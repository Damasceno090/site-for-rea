No contexto de tecnologia e inteligência artificial, REA significa Reverse Engineer Anything. É um projeto de código aberto (licença MIT) que funciona como um servidor MCP (Model Context Protocol) e CLI. Ele conecta agentes de IA (como Claude Code, Cursor ou Codex) a ferramentas de engenharia reversa (como Ghidra, IDA Pro ou Hopper). O objetivo é permitir que o agente de IA investigue aplicativos, binários ou código compilado sem ter acesso ao código-fonte original, executando um fluxo de decompilar, entender e recriar funcionalidades com base em evidências técnicas. O projeto é mantido pelo desenvolvedor morluto no GitHub.
